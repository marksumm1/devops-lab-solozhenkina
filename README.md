## План изучения DevOps

1. Изучить основы Git и GitHub.
2. Освоить работу с ветками и Pull Request.
3. Познакомиться с принципами CI/CD.
4. Изучить основы контейнеризации с Docker.
5. Познакомиться с развёртыванием и мониторингом приложений.
